- [The right sidebar has two tabs, Run and Tasks, 32 pixels tall; Run holds the referenced files, understanding, and subagents, Tasks the queue and previous tasks](.claude/reference/ui/components/right-sidebar/index.md#tabs)
- [While a task runs Run is selected as it starts unless Tasks was picked since the sidebar slid out; with none running Run is disabled and Tasks shown](.claude/reference/ui/components/right-sidebar/index.md#tabs)
- [The sidebar shows while a task runs, while anything is queued, or opened by hand from a button at the body tab bar's right end or Ctrl+Alt+B, on Tasks, staying until closed by hand](.claude/reference/ui/components/right-sidebar/index.md#showing)
- [The Tasks tab is one scrolling timeline in Previous, Running, and Queued groups, each headed with a muted label and count, empty ones saying so](.claude/reference/ui/components/right-sidebar/tasks/index.md#description)
- [Previous keeps the filters and batch actions; Queued keeps drag reordering, auto-send, and Send next](.claude/reference/ui/components/right-sidebar/tasks/index.md#description)
- [Each task is a 28 pixel row: mode-colour bar, status or queue place, first line, muted duration; a chain one row with its steps indented beneath, collapsed](.claude/reference/ui/components/right-sidebar/tasks/index.md#rows)
- [Clicking a row opens the task in the tab with a back arrow, mode, and name; Escape goes back; its output shows in the message list with a "Back to the latest task" bar](.claude/reference/ui/components/right-sidebar/tasks/index.md#details)
- [An open task shows at-a-glance figures, its prompt, its parameters, and its actions](.claude/reference/ui/components/right-sidebar/tasks/index.md#details)
- [A queued task is edited in place, each change saved, held while open; a task that has run reads as sent and offers "Edit and resend"](.claude/reference/ui/components/right-sidebar/tasks/index.md#details)
- [A Chain task lists its steps; "Add step" appends a Code or Spec step with its own prompt, saved in the chain's hidden anchor, run after the step before it](.claude/reference/ui/components/right-sidebar/tasks/index.md#chain-steps)
- [The message list holds only the header and the selected task's output; nothing lies past either end](.claude/reference/scope/prompt-mode/message-list/index.md#scrolling-past)
- [The queue is never above the chat input or in the message list](.claude/reference/scope/prompt-mode/queue-list/index.md#placement)
