- [The pointer can move into the popover to select text and click links; it closes once the pointer leaves both it and what was hovered, on Escape, or when the editor scrolls; passing over without resting shows nothing](.claude/reference/scope/editor/index.md#language-support)
- [Symbols (keys, anchor names, keywords, imported names, names in braces after $, # or @) send `textDocument/hover` with the unsaved text synced first; the answer is markdown, code blocks highlighted as Piton, links opening as the editor opens links](.claude/reference/scope/editor/index.md#language-support)
- [An answer after the pointer has left is dropped; prose, numbers, punctuation, comments and blanks are never hovered; an empty or same-words-again answer opens nothing](.claude/reference/scope/editor/index.md#language-support)
- [On an error anywhere along its underline, prose included, the popover lists each diagnostic: its severity's icon in the error, warning, or info colour, its message, then muted its code and related notes, each a link to where it points](.claude/reference/scope/editor/index.md#language-support)
- [On an error over a symbol, the symbol's hover follows beneath a thin line; where the server offers fixes, a "Quick fix" link with Ctrl+. (Cmd+. on macOS) lists them as the shortcut does](.claude/reference/scope/editor/index.md#language-support)
- [Typing closes the popover as soon as a key changes the text; nothing opens again until the pointer next moves over the text](.claude/reference/scope/editor/index.md#language-support)
