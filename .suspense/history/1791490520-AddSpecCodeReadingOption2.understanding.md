- [Letting Spec runs read the code is a project setting, off until switched on, saved in .suspense/settings.json](.claude/reference/scope/project-data/index.md#contents)
- [With it off, a Spec run gets an empty writable scratch directory in place of the code location, as before](.claude/reference/scope/container-environment/index.md#spec)
- [With it on, a Spec task or Chain spec step gets the code location mounted read only, as a question does](.claude/reference/scope/container-environment/index.md#spec)
- [With it on, writable scratch is mounted over the code location's CLAUDE.md or AGENTS.md guidance files alone, so piton build writes guidance there, not into the code](.claude/reference/scope/container-environment/index.md#spec)
- [Where the code location holds the spec, the spec is still mounted read and write over it, and project data left out](.claude/reference/scope/container-environment/index.md#spec)
- [A Spec run may still write only the spec, the reference, .piton, and its understanding file](.claude/reference/scope/container-environment/index.md#spec)
- [The setting takes effect from the next run; a running one keeps its mounts](.claude/reference/scope/container-environment/index.md#spec)
- [With it on, spec-lane runs fill CODE_LOCATION in, and are told on a paragraph of its own that the code is read only, for reading, never changing](.claude/reference/scope/prompt-mode/mode-system-prompts/index.md#templates)
